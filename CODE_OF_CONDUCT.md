# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
v2.1. In short: be kind, be respectful, no harassment, no discrimination.

Scope: issues, pull requests, discussions, and any other project spaces.

Enforcement: violations may lead to warnings or bans at the maintainer's
discretion. Reports go through the contact on the repo owner's profile and
are handled confidentially.
